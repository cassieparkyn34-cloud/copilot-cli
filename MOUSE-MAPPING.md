# 🖱️ Mouse Mapping

Welcome to the mouse mapping feature in GitHub Copilot CLI!

## What is this?

Mouse mapping is a powerful feature that enables you to configure custom mouse 
interactions within your terminal when using GitHub Copilot CLI. This feature 
brings point-and-click convenience to your command-line workflows.

## How to enable mouse mapping

Launch the CLI with the `--mouse` flag to enable mouse support:

```bash
copilot --mouse
```

This will activate mouse tracking in your terminal, allowing you to interact 
with the CLI using your mouse in addition to keyboard commands.

## What can you do?

With mouse mapping enabled, you can:

- **Click to select**: Click on suggestions or options to select them
- **Scroll through results**: Use your mouse wheel to navigate long outputs
- **Drag to select text**: Select text more intuitively with mouse gestures
- **Right-click for context**: Access context menus for additional actions

## Compatibility

Mouse mapping works best with modern terminal emulators that support mouse 
events, including:

- iTerm2 (macOS)
- Windows Terminal
- GNOME Terminal
- Alacritty
- And many more!

## Tips

- Combine mouse mapping with keyboard shortcuts for maximum productivity
- Mouse support respects your terminal's existing mouse configuration
- You can disable mouse mode anytime by launching without the `--mouse` flag

Happy clicking! 🖱️✨
